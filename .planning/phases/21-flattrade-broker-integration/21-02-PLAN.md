# Plan: Phase 21 - Plan 02: Multi-Broker Admin Dashboard UI & Global Control

## Goal
Integrate the downloaded Stitch designs into a production-grade Admin Dashboard (`/admin`), providing complete multi-broker gateway management, multi-account execution controls, risk sliders, live account statuses, and emergency kill switches.

## Tasks
- [x] Create `templates/admin.html` adapting the Stitch designs (`broker_gateway.html`, `multi_account_terminal.html`, `risk_limits.html`):
  - Gateway & Auth Hub tab: Live status cards for Dhan, Groww, FlatTrade (UCC, status, active token, API key/TOTP inputs, Reconnect and Ping buttons, toggle on/off).
  - Multi-Account Execution tab: Per-broker lot multipliers, aggregate PnL, open positions across all accounts, order feed with broker tags (`DHAN`, `GROWW`, `FLAT`).
  - Risk & Global Limits tab: Margin utilization, drawdown limit, feeling gate sentiment status, and individual broker kill switches.
  - Emergency Master Kill switch: Kills positions across ALL active accounts instantly.
- [x] Add backend endpoints in `server.py`:
  - `GET /admin`: Render the Admin Dashboard.
  - `GET /api/accounts`: Return JSON payload of all accounts, connection health, token expiry, margins, and lot multipliers.
  - `POST /api/accounts/toggle`: Enable/disable broker in multi-routing.
  - `POST /api/accounts/lot-multiplier`: Update lot multiplier per broker.
  - `POST /api/accounts/login/<broker>`: Trigger headless login / token refresh for Dhan, Groww, or FlatTrade.
  - `POST /api/accounts/kill/<broker>`: Emergency kill switch for a specific broker or `all`.
  - `GET /api/accounts/ping`: Ping all active broker gateways and return latency.
- [x] Update `templates/index.html`:
  - Add navigation link to `/admin` in the header.
  - Add real-time triple-broker status badges in the main dashboard navigation bar (`Dhan: Active | Groww: Active | FlatTrade: Active`).
- [x] Create `tests/test_admin_dashboard.py`:
  - Test `/admin` template rendering.
  - Test `/api/accounts` endpoint output.
  - Test `/api/accounts/toggle` and lot multiplier updates.
  - Test `/api/accounts/kill/<broker>` route.
- [x] Run full test suite (`pytest tests/`) ensuring 100% pass rate.
