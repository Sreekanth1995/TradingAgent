# Plan: Phase 21 - Plan 01: FlatTrade Broker Client & Dedicated Services

## Goal
Implement `FlatTradeClient` facade and dedicated domain services (`FlatTradeAuthService`, `FlatTradeOrderService`, `FlatTradeInstrumentService`, `MockFlatTradeClient`) adhering to FlatTrade's Noren OMS API and `broker/interfaces.py` contracts.

## Tasks
- [x] Create `broker/flattrade/__init__.py` and dedicated services:
  - `broker/flattrade/auth_service.py`: Automated headless token generation using `pyotp` TOTP and SHA-256 session hash (`sha256(api_key + request_code + api_secret)`), storing in Redis (`tokens:flattrade:token`).
  - `broker/flattrade/instrument_service.py`: Canonical exchange symbol bridge (`exchange='NFO'`, `tradingsymbol='NIFTY24DEC24000CE'`).
  - `broker/flattrade/order_service.py`: Intraday MIS (`product_type='I'`, `price_type='MKT'`) order placement, Stop-Loss leg arming, modifying open SL order to Market on reversal/exit (`modify_order(orderno, newprice_type='MKT')`), cancellation, position retrieval (`get_positions`), and limits check (`get_limits`).
  - `broker/flattrade/client.py`: `FlatTradeClient` facade implementing broker protocols.
  - `broker/flattrade/mock_client.py`: `MockFlatTradeClient` for 100% offline testing.
- [x] Create `tests/test_flattrade_client.py`:
  - Test session token generation.
  - Test instrument symbol mapping.
  - Test order placement and Stop-Loss arming.
  - Test modification of SL leg to Market on reversal.
  - Test positions and limits parsing.
- [x] Run test suite (`pytest tests/test_flattrade_client.py`) and verify pass.
