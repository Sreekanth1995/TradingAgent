# Plan: Phase 20 - Plan 01: Groww Broker Client & Dedicated Services

## Goal
Implement `GrowwClient` facade and dedicated domain services (`GrowwAuthService`, `GrowwOrderService`, `GrowwInstrumentService`, `MockGrowwClient`) conforming strictly to official `growwapi` SDK methods and `broker/interfaces.py` contracts with offline mockability.

## Tasks
- [x] Create `broker/groww/__init__.py` and dedicated services:
  - `broker/groww/auth_service.py`: Automated headless token generation using `GrowwAPI.get_access_token(api_key, totp)` via `pyotp.TOTP`, token storage in Redis (`tokens:groww:access_token`).
  - `broker/groww/instrument_service.py`: Canonical exchange trading symbol bridge (maps underlying, strike, and expiry to standard symbol like `NIFTY24DEC24000CE`).
  - `broker/groww/order_service.py`: Order execution implementing MARKET entry (`groww.place_order(...)` with `product=PRODUCT_MIS`), arming native OCO Smart Orders (`groww.create_smart_order(...)`), modifying OCO legs towards LTP on reversal, cancellation, position retrieval (`get_positions_for_user`), and margin checks (`get_available_margin_details`).
  - `broker/groww/client.py`: `GrowwClient` facade delegating to the domain services, matching `DhanClient` interface.
  - `broker/groww/mock_client.py`: `MockGrowwClient` with realistic in-memory order matching, OCO brackets, positions, and margins for 100% offline testing.
- [x] Create `tests/test_groww_client.py`:
  - Test auth token generation and Redis caching.
  - Test instrument symbol resolution.
  - Test market entry + OCO bracket arming.
  - Test smart exit OCO leg modification towards LTP.
  - Test positions and margin parsing.
- [x] Run test suite (`pytest tests/test_groww_client.py`) and verify pass.
